# ARLinux Installer

Official backup mirror of the ARLinux Android installer.

- [Download the latest APK from GitHub](https://github.com/taowen/arlinux-installer/releases/download/latest/arlinux-latest.apk)
- [Primary download](https://download.arlinux.com/android/latest.apk)
- [Website](https://arlinux.com)
- [Open-source Linux distribution and Guest Tools](https://github.com/taowen/arlinux-rootfs)

The `latest` release contains `arlinux-latest.apk`, replaced when a new public
ARLinux version is published. It mirrors the exact signed APK from the primary
download; it is not a separate updater app. The release description identifies
the version and SHA-256.

Maintainers publish through the ARLinux application's `build.ps1 publish` entry;
there is no separate build pipeline in this mirror repository.
